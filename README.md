# Gift Index

Локальная витрина коллекционных подарков. Она объединяет коллекции в один список, сортирует предложения сначала по самой низкой цене и не показывает покупателю, откуда загружено объявление.

## Запуск

Запустите `run_catalog.bat` и откройте `http://127.0.0.1:8766`.

## Цена

Курс TON/RUB обновляется с кэшем на 5 минут. К цене предложения добавляются 7,5% маржи и 6% комиссии, затем сумма округляется вверх до ближайших 5 ₽.

Ключи читаются сервером из локальной папки Cardinal и не попадают в страницу или адреса запросов. Сервер привязан к `127.0.0.1`.

Оформление покупки и создание FunPay-лота в текущей витрине пока не подключены.
