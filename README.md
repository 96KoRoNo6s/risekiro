# RiseKiro

Витрина подарков Telegram на GitHub Pages: http://sculpt.run

Публичный каталог работает без ключей аккаунта и без локального сервера. Фильтры коллекции, модели, фона, узора и цены; цены в рублях округляются вверх до ближайших 5. Анимация в подробном просмотре и при наведении на компьютере. Параметры расчёта находятся в catalog-config.json.

Покупатель копирует код подарка и отправляет продавцу в FunPay. Проверка, создание персонального предложения и передача выполняются установленным плагином Cardinal.
