# LeadMatrix Crypto Luxury — Instagram Lead Engine

Веб-приложение для поиска, фильтрации и выгрузки активных Instagram-аккаунтов по 12 направлениям люкс-аренды и покупки товаров за криптовалюту (USDT / BTC).

## 🚀 Как запустить проект:

### Вариант 1: Просто открыть в браузере (Без установки)
Двойной клик по файлу `index.html` — приложение откроется в любом современном браузере.

### Вариант 2: Запуск локального сервера (Node.js)
1. Убедитесь, что установлен Node.js.
2. В терминале папки проекта выполните:
   ```bash
   npm install
   npm run dev
   ```
3. Приложение откроется по адресу `http://localhost:3000`.

## 🌟 Основные возможности:
- **12 Люкс Категорий:** Аренда Яхт, Вилл, Суперкаров, Джетов, Шале, а также Покупка Ювелирки, Недвижимости и Авто за Крипту (USDT/BTC).
- **5 Международных ГЕО:** Дубай, Майами, Европа, СНГ, Азия.
- **Повторный Запрос (Генератор Партий):** Выгрузка от 25 до 500 новых уникальных аккаунтов без повторов.
- **Проверка Дубликатов:** Фильтрация пользовательских списков.
- **DM ➔ WhatsApp Воронка:** Скрипты первого сообщения для перехода в WhatsApp.
- **Экспорт:** Копирование ссылок в 1 клик и скачивание CSV-таблиц.
